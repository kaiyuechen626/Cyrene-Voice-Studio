## 手机后续验收顺序

1. 先备份原音色；确认新 APK 签名与旧安装版一致，否则不要覆盖或卸载旧版。
2. 在独立应用中用有权使用的参考短句创建新角色，输入不同文本试听，验证 WAV 与音色包导出。
3. 用支持引擎选择的应用枚举并选择音色，分别测试 `speak`、`synthesizeToFile`、取消后重发及长文。
4. 分别检查断网、按 Home、锁屏；记录实际等待与错误，特别检查三星后台冻结。
5. Muse 保持当前已验收的应用内引擎，确认原聊天、音色、暂停/继续及后台播放正常，不依赖外部引擎测试成功才能使用。
