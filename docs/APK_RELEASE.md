# 0.2.0 APK 预览版

[下载 ARM64 安装包](https://github.com/kaiyuechen626/Cyrene-Voice-Studio/releases/download/v0.2.0-preview.1/Cyrene-Voice-Studio-0.2.0-arm64-v8a.apk)

适用于 Android 8.0 以上 ARM64 手机，包括 Galaxy S25。下载后在手机文件管理器中点击 APK，根据系统提示允许本次安装。它是可安装的 Release 构建，未开启调试；本次未进行新版真机验收，因此以预览版提供。

## 已有旧版

包名仍是 `io.cyrene.voice`，版本 0.2.0，版本号 6。为了保留本项目旧版 0.1.4 的覆盖升级能力，预览版沿用原有 Android Debug 证书。证书 SHA-256：

`df847fecd7664eb0bd60929ca3f0ff933b5767565fdf3e5454e1d328ff740075`

此为沿用旧开发签名的兼容预览包，并未迁移为独立的生产签名。签名私钥不会发布。发布者应长期保护并备份原签名；不能用其他电脑默认生成的同名证书替换它。

安装前建议先在旧版导出个人音色包作备份。若系统提示签名冲突或无法覆盖，不要卸载旧版；先核对已有应用和下载包。没有在本次操作中替换手机应用、删除音色或修改 Muse。

## 首次使用

APK 不包含模型、录音或预置角色，也没有联网下载功能。先按照[模型准备](MODELS.md)导入基础 `.cyvoice` 包，再导入自己的参考录音及准确原文创建角色。已有角色数据在签名兼容的正常覆盖升级中保留，但仍需由用户验收。
